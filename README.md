# 一凡拼图 (Yifan Puzzle) · iOS 横屏益智拼图游戏

一款专为 iPhone 打造的沉浸式横屏益智拼图游戏。内置 10 款绚丽的自然风景插画（富含天空渐变与林木元素），提供 5 级平滑进阶难度梯度（35 / 70 / 160 / 350 / 700 块），具备 3D 浮雕厚度质感、微敲击音效、触觉震动反馈及智能磁吸拼合手感。

---

## 核心特色

1. **五级进阶梯度 (先缓后陡)**
   - **第 1 级 (初出茅庐)**: 35 块 (7×5 网格)
   - **第 2 级 (渐入佳境)**: 70 块 (10×7 网格)
   - **第 3 级 (熟能生巧)**: 160 块 (16×10 网格)
   - **第 4 级 (炉火纯青)**: 350 块 (25×14 网格)
   - **第 5 级 (登峰造极)**: 700 块 (35×20 网格)

2. **匠心拼合手感**
   - **自动磁吸**: 碎片靠近正确板位（约 45% 阈值）平滑弹簧入位并锁定。
   - **相邻咬合联动**: 未归位的碎片如果在散落区拼对，会自动咬合成组，整组支持一体化拖拽。
   - **五格临时托盘**: 游戏底部常驻 5 格收纳托盘，碎片随拖随存，解决多块碎片杂乱问题。
   - **区域调节滑块**: 左侧拼图板与右侧堆放区之间设置可拖拽滑块，支持 55%~85% 比例动态调整。

3. **自由角度旋转开关**
   - **开启**: 碎片散落带随机角度，需要双指旋转对准方向后才允许磁吸。
   - **关闭**: 所有碎片保持正向摆放，无需人工旋转。

4. **3D 视觉与沉浸反馈**
   - 碎片具备斜角高光与挤压截面暗影，呈现硬木板/高档卡纸真实厚度感。
   - 拾取时放大 1.08 倍并投射桌面动态悬浮阴影。
   - 内置 CoreMotion 陀螺仪视差与 16-bit PCM 清脆咔哒微敲击音效。

5. **面向 500+ 张图案的架构**
   - 运行时程序化贝塞尔切片引擎，基于图片 Hash Seed 实时切割，无需预切静态图。
   - 支持从 `PuzzleImages/` 及沙盒 Documents 动态扫描扩充。

## IPA 签名安装教程 (iPhone 手机端安装)

GitHub Actions 会自动为每次代码提交生成未签名的 `YifanPuzzle-unsigned.ipa` 安装包。请在 **GitHub Actions Artifacts** 或 **Releases** 页面下载安装包后，通过以下任一方式完成签名与安装：

### 方法一：使用 Sideloadly (推荐，支持 Windows / Mac)
1. 电脑下载并安装 [Sideloadly](https://sideloadly.io/)。
2. 用数据线将 iPhone 连接至电脑，并选择“信任此电脑”。
3. 打开 Sideloadly，将下载的 `YifanPuzzle-unsigned.ipa` 拖入窗口。
4. 输入你的个人 Apple ID 账号及密码（免费个人证书）。
5. 点击 **Start** 开始自动签名并推送到手机。
6. 安装完成后，在 iPhone 进入 **设置 > 通用 > VPN 与设备管理**，找到你的 Apple ID 证书并点击 **信任**，即可在主屏幕打开游戏畅玩。

### 方法二：使用 TrollStore (巨魔商店，永久免签，iOS 14.0 - 17.0)
1. 如果你的 iPhone 处于 TrollStore 支持的系统版本并已安装 TrollStore。
2. 在手机 Safari 浏览器中直接下载 IPA 文件。
3. 选择“共享”到 **TrollStore**，点击 **Install** 即可秒级安装，永久不过期且无需证书。

### 方法三：使用 AltStore
1. 电脑端部署 AltServer 并连接手机安装 AltStore。
2. 在手机端 AltStore 中点击左上角 `+`，选择下载的 IPA 文件进行签名安装。

### 方法四：手机端直接签名 (全能签 / 轻松签 eSign)
1. 在手机端打开已导入有效证书的轻松签或全能签。
2. 导入 `YifanPuzzle-unsigned.ipa`，点击签名并安装。

## 开发与编译

本项目基于 Swift 5.9 + SpriteKit + SwiftUI 开发，工程结构由 **XcodeGen** 维护。

```bash
# 生成 Xcode 工程
xcodegen generate

# 打开工程编译运行
open YifanPuzzle.xcodeproj
```
